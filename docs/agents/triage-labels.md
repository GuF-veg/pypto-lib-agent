# Triage labels

Engineering skills use five canonical triage roles. Map each role to the
corresponding label in this repo's issue tracker.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use the tracker label whenever a skill refers to a canonical role.
Edit the tracker-label column to change this vocabulary later.
